Hugo starter for Indian government achievements showcase

Overview
- Minimal Hugo site scaffolded for content-driven exhibition of government achievements.
- Includes a `GIGW_CHECKLIST.md` and `RECOMMENDATIONS.md` with theme suggestions and adaptation notes.

Quick preview (install Hugo first)

```bash
# install Hugo (macOS / Homebrew)
brew install hugo

# in project root
hugo server -D
```

Files of interest
- `config.toml` — site config
- `content/_index.md` — homepage content
- `layouts/_default/baseof.html` — base layout with accessibility features
- `layouts/index.html` — homepage template
- `static/css/styles.css` — minimal styles
- `GIGW_CHECKLIST.md` — implementation checklist for Guidelines for Indian Government Websites
- `RECOMMENDATIONS.md` — 3 theme recommendations and adaptation steps
