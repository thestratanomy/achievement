Simple static showcase

To preview the standalone page:

```bash
# from project root
cd static-site
# serve on port 8000
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

This page is independent of Hugo — use it if Hugo's server isn't behaving. It follows basic accessibility and GIGW-friendly patterns (semantic headings, skip link, color contrast).
